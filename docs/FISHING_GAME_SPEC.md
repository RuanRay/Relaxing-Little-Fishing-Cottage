# 日式海島第一人稱釣魚遊戲｜功能規劃文檔

Oct 2, 2026 · @阮梓睿

## 專案概述

以既有的「日式幻想海島」微縮場景為舞台，做一款可在桌機瀏覽器遊玩的第一人稱釣魚遊戲，開發總時程 90 分鐘。

| 項目 | 規格 |
| --- | --- |
| 交付物 | 單一 HTML 檔，CSS 與 JS 全部內嵌 |
| 引擎 | Three.js（UMD 版本，CDN 載入）+ PointerLockControls + OrbitControls |
| 平台 | 桌機瀏覽器，滑鼠＋鍵盤 |
| 美術 | 三渲二卡通渲染，基本幾何體建模，不使用外部貼圖 |
| 資料保存 | 僅存在記憶體，重新整理即清空 |
| 本輪不做 | 手機觸控操作、存檔、多人、商店與升級系統 |

開發方式以 AI 輔助生成程式碼為主，產出後交由其他工具做錯誤驗證與效能評判，因此每個模組都需有可獨立檢查的驗收條件（見最後一節）。

## 已定案決策

三項前提已確認，開發時不再重議。

- **開場環繞，點擊轉第一人稱**：載入後先以 OrbitControls 自動緩慢環繞，展示正方形懸浮底座與岩層側壁；玩家點擊畫面後，鏡頭在 1.5 秒內平滑移動到碼頭起點，切換為第一人稱。
- **解除「畫面不出現 UI」限制**：遊戲所需的準心、蓄力條、張力條、魚卡與圖鑑可以顯示，但採情境式出現，不用時隱藏。
- **場景提示詞原文不改**：海島、木屋、碼頭的美術描述沿用原提示詞；遊戲功能是疊加在場景之上的一層，本文件不修改原文。

## 核心玩法循環

一輪釣魚約 20–40 秒，玩家反覆執行以下流程，目標是收集圖鑑中的全部魚種。

1. 在島上自由走動，走到碼頭末端或沙灘水邊。
2. 按住滑鼠左鍵蓄力，放開後拋竿，蓄力越久拋得越遠。
3. 浮標落水後等待 3–8 秒（隨機），期間浮標隨水面輕微起伏。
4. 魚咬鉤時浮標下沉並濺起水花，玩家需在 0.8 秒內點擊左鍵收竿。
5. 進入張力小遊戲：按住左鍵收線、放開放線，讓張力維持在安全區直到進度滿格。
6. 成功則跳出魚卡（名稱、重量、稀有度）並寫入圖鑑；失敗則顯示「魚跑掉了」。
7. 回到步驟 2 繼續釣，或移動到其他水域。

拋竿落點決定水域：碼頭兩側為淺灘，碼頭末端前方為深水，不同水域出現的魚種不同，提供移動的理由。

## 系統模組結構

程式分為 9 個模組，在單一 HTML 內以註解分區；每幀由主迴圈依序呼叫各模組的 update(dt)。

| 模組 | 職責 | 關鍵需求 | 優先級 |
| --- | --- | --- | --- |
| Scene | 建立底座、海島、木屋、碼頭、水面、光源 | MeshToonMaterial + 背面放大描邊；水面為半透明平面，頂點以 sin 波起伏 | 必要 |
| CameraDirector | 開場環繞與鏡頭過場 | 環繞時禁止玩家操作；點擊後 1.5 秒插值至碼頭起點並啟用 PointerLock | 必要 |
| Player | 第一人稱移動 | WASD 移動、Shift 加速；向下 raycast 貼地；底座邊緣隱形牆；可走區域為島面與碼頭 | 必要 |
| Rod | 釣竿模型與動作 | 固定於鏡頭右下；蓄力後仰、拋出前甩、收線抖動三種姿態 | 必要 |
| Bobber & Line | 浮標與釣線 | 拋物線飛行；落水判定；浮標隨波浮動；釣線用 Line 連接竿尖與浮標 | 必要 |
| FishingSystem | 狀態機與判定 | 驅動整個釣魚流程（見下一節）；依落點水域抽魚 | 必要 |
| FishData | 魚種資料 | 純資料陣列，可直接增修，不寫死在邏輯內 | 必要 |
| HUD | 情境式介面 | 準心、蓄力條、張力條、魚卡、提示字；以 DOM 疊加在畫布上 | 必要 |
| Collection | 圖鑑與漁獲紀錄 | Tab 鍵開關；未釣到的魚顯示剪影與「？？？」 | 次要 |

音效（拋竿、水花、咬鉤提示）與水中游魚動畫列為加分項，見時程一節的砍項順序。

## 釣魚狀態機

FishingSystem 以單一變數 state 驅動全部流程，任何時刻只會處於 8 個狀態之一。

&#91;embedded content: 釣魚狀態機 · 8 個狀態\]

釣竿動作、浮標、HUD 都只讀取 state 決定自己的表現，不互相呼叫；除錯時只要在畫面角落印出 state，就能定位問題出在哪一段。

## 魚種資料表

首版 6 種魚，淺灘 3 種、深水 3 種；難度 1–5 決定張力條中魚的拉扯強度與安全區寬度。

| 魚種 | 水域 | 稀有度 | 出現權重 | 重量 (kg) | 難度 | 體色 |
| --- | --- | --- | --- | --- | --- | --- |
| 小丑魚 | 淺灘 | 普通 | 50 | 0.1–0.3 | 1 | 珊瑚橙 |
| 花枝 | 淺灘 | 普通 | 35 | 0.3–1.2 | 2 | 奶油白 |
| 河豚 | 淺灘 | 稀有 | 15 | 0.5–2.0 | 3 | 暖金色 |
| 竹筴魚 | 深水 | 普通 | 50 | 0.2–0.8 | 2 | 青綠色 |
| 真鯛 | 深水 | 稀有 | 35 | 1.0–5.0 | 4 | 鏽紅 |
| 鬼頭刀 | 深水 | 傳說 | 15 | 5.0–15.0 | 5 | 翠綠＋金 |

抽魚方式：依落點水域篩出 3 種，按出現權重隨機抽一隻，重量在範圍內均勻取值並四捨五入到小數點後一位。魚卡顯示的魚用基本幾何體拼出，顏色取「體色」欄。

## 操作與 UI 規格

操作只用滑鼠與 7 個按鍵；所有 UI 元素只在對應狀態出現。

| 輸入 | 功能 |
| --- | --- |
| 點擊畫面（開場時） | 結束環繞，進入第一人稱 |
| 滑鼠移動 | 轉動視角 |
| W A S D | 移動 |
| Shift | 加速移動 |
| 左鍵按住 / 放開 | 蓄力 / 拋竿；咬鉤時點擊收竿；張力遊戲中按住收線 |
| 右鍵 | 等待中取消拋竿，收回浮標 |
| Tab | 開關圖鑑 |
| Esc | 釋放滑鼠並暫停 |

| UI 元素 | 出現時機 | 位置 |
| --- | --- | --- |
| 開場標題與「點擊開始」 | 環繞中 | 畫面中央偏下 |
| 準心 | 第一人稱全程 | 畫面正中央 |
| 蓄力條 | 按住左鍵蓄力時 | 準心下方 |
| 「！」咬鉤提示 | 咬鉤的 0.8 秒內 | 準心上方 |
| 張力條與進度條 | 收線小遊戲中 | 畫面右側直立 |
| 魚卡 | 釣到後 3 秒，可點擊關閉 | 畫面中央 |
| 結果提示字 | 脫鉤或拋到陸地時 | 準心下方，1.5 秒淡出 |
| 暫停畫面 | 按 Esc 後 | 全畫面半透明遮罩 |
| 圖鑑 | 按 Tab 後 | 全畫面卡片格 |

UI 風格延續場景：圓角、奶油白底、深綠描邊、海洋藍與珊瑚橙作為狀態色。

## 時程分配與砍項順序

90 分鐘分為 6 個階段，第 70 分鐘是唯一的硬檢查點：此時必須能從拋竿一路釣到魚。

&#91;embedded content: 開發時程 · 90 分鐘 · 6 個階段\]

第 70 分鐘若核心循環仍未跑通，依序砍掉以下項目，把時間讓給核心循環。

1. 水中游魚動畫
2. 音效
3. 圖鑑頁（保留魚卡）
4. 底座側壁細節：貝殼、珊瑚碎片、垂落藤蔓
5. 木屋與碼頭的小道具（保留建築主體與碼頭本體）

「場景」階段是最容易超時的一段：原提示詞道具清單很長，第 20 分鐘一到就停手，缺的道具移到測試階段有空再補。
